# トラック配送管理システム（HTML/JavaScript版）

シンプルなHTML + JavaScript + LocalStorageで構築されたスタンドアロンアプリケーション

**本番環境**: https://truck-delivery-system.vercel.app

## ✨ 特徴

- ✅ インストール不要
- ✅ サーバー不要
- ✅ オフラインで動作
- ✅ すぐに使える

## 🚀 クイックスタート

### 方法1: 直接開く
`index.html` をダブルクリックしてブラウザで開くだけ！

### 方法2: ローカルサーバー
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

ブラウザで `http://localhost:8000` にアクセス

## 📋 主な機能

### 🏠 ダッシュボード
- 今日の配送一覧
- 明日の配送一覧
- 運転中の配送
- 注意が必要な配送（24時間以内開始）
- 今月のサマリー統計

### 📅 配送管理
- カレンダー表示（日付×トラックのマトリックス）
- リスト表示（検索・フィルタリング）
- 配送登録・編集・削除・複製
- ステータス管理（予定・運転中・完了）
- ソート機能
- 高度な検索（日付範囲、トラック、顧客、ステータス）

### 🚚 トラックマスタ
- トラック情報の管理
- 検索機能

### 👥 顧客マスタ
- 顧客情報の管理
- 検索機能

### 📊 統計・レポート
- 配送統計
- トラック稼働率グラフ
- 顧客別配送回数ランキング
- 月別配送推移

### 💾 データ管理
- CSVエクスポート/インポート
- JSONバックアップ
- データ削除

### 🖨️ 印刷/PDF出力
- すべての画面から印刷可能

### ⌨️ キーボードショートカット
- `Ctrl + H`: ダッシュボード
- `Ctrl + D`: 配送管理
- `Ctrl + T`: トラックマスタ
- `Ctrl + C`: 顧客マスタ
- `Ctrl + R`: 統計・レポート
- `Ctrl + N`: 新規登録
- `Ctrl + P`: 印刷
- `Esc`: モーダルを閉じる

## 💾 データ保存

ブラウザの **localStorage** を使用してデータを保存します。

### 注意事項
- ⚠️ ブラウザのキャッシュをクリアすると、データが消去されます
- ⚠️ 定期的にCSV/JSONでバックアップを取ってください

## 🐛 トラブルシューティング

### データが消えた
- ブラウザのキャッシュをクリアすると、データが消去されます
- **対策**: データ管理タブから定期的にバックアップを取ってください

### トラックが選択できない
- そのトラックは、選択した日時で既に配送が予約されています
- **対策**: 別の時間帯または別のトラックを選択してください

### トラック/顧客が削除できない
- 配送記録があるトラックや顧客は、データ整合性保護のため削除できません
- **対策**: 先に関連する配送記録を削除してから、再度お試しください
