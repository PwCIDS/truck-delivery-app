# トラック配送管理システム

このリポジトリには、2つのバージョンのトラック配送管理システムが含まれています。

## 📦 プロジェクト構成

### 1. HTML/JavaScript版（このディレクトリ）
シンプルなHTML + JavaScript + LocalStorageで構築されたスタンドアロンアプリケーション

**特徴:**
- ✅ インストール不要
- ✅ サーバー不要
- ✅ オフラインで動作
- ✅ すぐに使える

**使い方:**
`index.html` をブラウザで開くだけ！

### 2. Next.js版（別リポジトリ/フォルダ）
Next.js + TypeScript + PostgreSQLで構築されたフルスタックアプリケーション

**本番環境**: https://truck-delivery-nextjs.vercel.app

---

## 🚀 クイックスタート（HTML/JavaScript版）

### インストール
インストール不要！以下のファイルが揃っていればOK：
- `index.html`
- `styles.css`
- `database.js`
- `app.js`

### 起動方法
**方法1: 直接開く**
```bash
# index.html をダブルクリックしてブラウザで開く
```

**方法2: ローカルサーバー**
```bash

python -m http.server 8000

# Node.js
npx http-server
```

ブラウザで `http://localhost:8000` にアクセス

## 📋 主な機能（HTML/JavaScript版）

### 🏠 ダッシュボード
- 今日の配送一覧
- 明日の配送一覧
- 運転中の配送
- 注意が必要な配送（24時間以内開始）
- 今月のサマリー統計

### 📅 配送管理
- **カレンダー表示**: 月単位でトラックの稼働状況をマトリックス形式で表示
- **リスト表示**: 配送情報を一覧表形式で表示、検索・フィルタリング機能付き
- **配送登録**: トラック、顧客、日付、時間、行先、積載内容を登録
- **ステータス管理**: 予定・運転中・完了のステータスを手動変更可能
- **配送複製**: 既存の配送を簡単に複製
- **ソート機能**: 出発日時、到着日時、ステータスでソート
- **高度な検索**: キーワード、トラック、顧客、ステータス、日付範囲でフィルタ

### 🚚 トラックマスタ
- トラック情報の登録・編集・削除
- トラックNo、車両番号、最大積載量、購入日を管理
- 検索機能（トラックNo・車両番号）
- 配送記録があるトラックは削除不可（データ整合性保護）

### 👥 顧客マスタ
- 顧客情報の登録・編集・削除
- 顧客コード、顧客名、住所、電話番号、担当者を管理
- 検索機能（顧客コード・顧客名・住所）
- 配送記録がある顧客は削除不可（データ整合性保護）

### 📊 統計・レポート
- 配送統計（総配送数、今月の配送数、完了済み、運転中）
- トラック稼働率の横棒グラフ
- 顧客別配送回数ランキング（上位10件）
- 月別配送推移（直近6ヶ月）

### 💾 データ管理
- **CSVエクスポート**: 配送、トラック、顧客データを個別にエクスポート
- **JSONバックアップ**: 全データを一括バックアップ
- **CSVインポート**: バックアップデータからの復元
- **データ削除**: 全データを削除（二重確認付き）

### 🖨️ 印刷/PDF出力
- すべての画面から印刷可能
- ブラウザの印刷機能でPDF保存

### ⌨️ キーボードショートカット
- `Ctrl + H`: ダッシュボード
- `Ctrl + D`: 配送管理
- `Ctrl + T`: トラックマスタ
- `Ctrl + C`: 顧客マスタ
- `Ctrl + R`: 統計・レポート
- `Ctrl + N`: 新規登録（現在の画面）
- `Ctrl + P`: 印刷
- `Esc`: モーダルを閉じる

## 💾 データ保存について

このアプリケーションは、ブラウザの **localStorage** を使用してデータを保存します。

### 特徴
- ✅ インターネット接続不要
- ✅ サーバー不要
- ✅ データはブラウザ内に保存

### 注意事項
- ⚠️ ブラウザのキャッシュをクリアすると、データが消去されます
- ⚠️ 同じブラウザ・同じPC内でのみデータが共有されます
- ⚠️ 別のPC・別のブラウザではデータは共有されません

### バックアップ方法
**推奨**: データ管理タブからCSV/JSONエクスポート

または手動で：
1. F12キーを押して開発者ツールを開く
2. 「Application」または「ストレージ」タブを選択
3. 「Local Storage」を展開
4. データをコピーして保存

## 🐛 トラブルシューティング

### データが消えた
- ブラウザのキャッシュをクリアすると、データが消去されます
- **対策**: データ管理タブから定期的にバックアップを取ってください

### トラックが選択できない
- そのトラックは、選択した日時で既に配送が予約されています
- **対策**: 別の時間帯または別のトラックを選択してください

### トラック/顧客が削除できない
- 配送記録があるトラックや顧客は、データ整合性保護のため削除できません
- **対策**: 先に関連する配送記録を削除してから、再度お試しください
