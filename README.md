# トラック配送管理システム

トラックの配送を効率的に管理するためのWebアプリケーションです。

## 主な機能

### 1. 配送管理
- **カレンダー表示**: 月単位でトラックの稼働状況をマトリックス形式で表示
- **リスト表示**: 配送情報を一覧表形式で表示、検索・フィルタリング機能付き
- **配送登録**: トラック、顧客、日付、時間、行先、積載内容を登録
- **空き状況確認**: 運転中のトラックは自動的に選択不可に
- **時間帯チェック**: 同じトラックの時間重複を自動検出

###2. トラックマスタ
- トラック情報の登録・編集・削除
- トラックNo、車両番号、最大積載量、購入日を管理
- 配送記録があるトラックは削除不可（データ整合性保護）

### 3. 顧客マスタ
- 顧客情報の登録・編集・削除
- 顧客コード、顧客名、住所、電話番号、担当者を管理
- 配送記録がある顧客は削除不可（データ整合性保護）

## 使い方

### インストール
特別なインストールは不要です。以下のファイルを同じフォルダに配置してください：
- index.html
- styles.css
- database.js
- app.js

### 起動方法
1. `index.html` をダブルクリックして、Webブラウザで開く
2. または、ローカルサーバーを起動する場合:
   ```bash
   # Python 3の場合
   python -m http.server 8000
   
   # Node.jsのhttp-serverを使用する場合
   npx http-server
   ```
3. ブラウザで `http://localhost:8000` にアクセス

### 基本操作

#### 配送を登録する
1. 「配送管理」タブを開く
2. 「+ 新規配送登録」ボタンをクリック
3. フォームに必要事項を入力
   - トラックを選択（空いているトラックのみ選択可能）
   - 顧客を選択
   - 配送日、出発時刻、帰着時刻を入力
   - 行先と積載内容を入力
4. 「登録」ボタンをクリック

#### カレンダー表示で確認する
- カレンダー表示では、横軸が日付、縦軸がトラック
- 青色のセルは配送予定あり
- 空白のセルは利用可能
- セルをクリックすると、その日付・トラックで配送を登録可能

#### リスト表示で検索する
1. 「リスト表示」ボタンをクリック
2. 検索ボックスで顧客名や行先などを検索
3. トラックやステータスでフィルタリング可能

#### トラックを追加する
1. 「トラックマスタ」タブを開く
2. 「+ 新規トラック登録」ボタンをクリック
3. トラック情報を入力
4. 「登録」ボタンをクリック

#### 顧客を追加する
1. 「顧客マスタ」タブを開く
2. 「+ 新規顧客登録」ボタンをクリック
3. 顧客情報を入力
4. 「登録」ボタンをクリック

## データ保存について

このアプリケーションは、ブラウザの**localStorage**を使用してデータを保存します。

### 特徴
- インターネット接続不要
- サーバー不要
- データはブラウザ内に保存

### 注意事項
- ブラウザのキャッシュをクリアすると、データが消去されます
- 同じブラウザ・同じPC内でのみデータが共有されます
- 別のPC・別のブラウザではデータは共有されません

### バックアップ方法
データをバックアップする場合は、ブラウザの開発者ツールを使用してください：
1. F12キーを押して開発者ツールを開く
2. 「Application」または「ストレージ」タブを選択
3. 「Local Storage」を展開
4. データをコピーして保存

## 動作環境

- 推奨ブラウザ: Google Chrome、Microsoft Edge、Firefox、Safari の最新版
- JavaScript有効化必須
- インターネット接続: 不要（オフラインで動作）

## トラブルシューティング

### データが消えた
- ブラウザのキャッシュをクリアすると、データが消去されます
- 定期的にバックアップを取ることをおすすめします

### トラックが選択できない
- そのトラックは、選択した日時で既に配送が予約されています
- 別の時間帯または別のトラックを選択してください

### トラック/顧客が削除できない
- 配送記録があるトラックや顧客は、データ整合性保護のため削除できません
- 先に関連する配送記録を削除してから、再度お試しください

## カスタマイズ

### 色の変更
`styles.css` ファイルで色をカスタマイズできます：
- `.nav-btn.active`: ナビゲーションボタンのアクティブ色
- `.btn-primary`: 主要ボタンの色
- `.calendar-cell.occupied`: 配送予定セルの色

### 機能の追加
`app.js` ファイルに機能を追加できます。
