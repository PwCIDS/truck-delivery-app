# トラック配送管理システム（HTML/JavaScript版）

シンプルなHTML + JavaScript + LocalStorageで構築されたスタンドアロンアプリケーション

**本番環境**: https://truck-delivery-system.vercel.app

## ✨ 特徴

- ✅ インストール不要
- ✅ サーバー不要
- ✅ オフラインで動作
- ✅ すぐに使える

## 🚀 クイックスタート

### 方法1: 直接開く
`index.html` をダブルクリックしてブラウザで開くだけ！

### 方法2: ローカルサーバー
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

ブラウザで `http://localhost:8000` にアクセス

## 🔧 Google Maps API設定（オプション）

Google Maps APIを設定すると、以下の高度な機能が利用できます：

### 必要な機能
1. **Google Maps JavaScript API** - 地図表示
2. **Directions API** - ルート計算・最適化
3. **Distance Matrix API** - 距離・時間計算
4. **Geocoding API** - 住所から座標への変換

### 設定手順
1. [Google Cloud Console](https://console.cloud.google.com/)にアクセス
2. プロジェクトを作成または選択
3. 「APIとサービス」→「認証情報」からAPIキーを作成
4. 上記4つのAPIを有効化
5. アプリの「統計・レポート」タブから「🔑 Google Maps APIキー設定」をクリック
6. 取得したAPIキーを入力して保存

**注意**: APIの使用には料金が発生する場合があります。[料金体系](https://cloud.google.com/maps-platform/pricing)を確認してください。

### APIキーなしでも使える機能
- 静的地図表示（SVGベース）
- 簡易的な距離計算
- 基本的なルート表示
- GPS追跡シミュレーション

## 🐛 トラブルシューティング

### データが消えた
- ブラウザのキャッシュをクリアすると、データが消去されます
- **対策**: データ管理タブから定期的にバックアップを取ってください

### トラックが選択できない
- そのトラックは、選択した日時で既に配送が予約されています
- **対策**: 別の時間帯または別のトラックを選択してください

### トラック/顧客が削除できない
- 配送記録があるトラックや顧客は、データ整合性保護のため削除できません
- **対策**: 先に関連する配送記録を削除してから、再度お試しください

### 通知が届かない
- ブラウザの通知権限が許可されていません
- **対策**: 統計・レポートタブから「🔓 通知権限リクエスト」をクリックして許可してください

### GPS追跡が動作しない
- 実際のGPSを使用する場合は、デバイスの位置情報サービスを有効にし、ブラウザに位置情報の使用を許可する必要があります
- **対策**: シミュレーションモードを使用するか、位置情報の権限を許可してください

### 地図が表示されない
- Google Maps APIキーが設定されていないか、無効です
- **対策**: APIキーを設定するか、静的地図表示を使用してください
